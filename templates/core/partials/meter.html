{% comment %} One utilisation bar (5a2G). Takes `meter` (a `Meter`), `label`, `used_text`, `total_text` and an optional `unit`. The two numbers arrive already formatted and separately, because bytes want `filesizeformat` and cores want `floatformat` and the composer deliberately holds no unit — and because building one joined string in the `include` tag would need the `add` filter, which returns the empty string the moment its two sides are not the same kind of thing. **An unknown meter draws no track at all.** Not an empty one: a node that did not report its swap and a node using none of it are opposite facts that a 0% bar spells identically, and the bar is the part an operator reads at a glance. The width is a custom property in a `style` attribute, the same idiom the tag chips use, which is what `style-src-attr 'unsafe-inline'` in the CSP is for. {% endcomment %}
